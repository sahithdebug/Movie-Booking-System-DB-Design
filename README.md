# Movie Ticket Booking and Snack Ordering System

A Database Management System (DBMS) project designed to provide an integrated platform for **movie ticket booking and cinema snack ordering**.

## Project Overview

The system allows customers to browse movies, select theatres and showtimes, choose available seats, order snacks, and complete payments digitally. It also provides administrative functionality for managing movies, theatres, screens, show schedules, ticket pricing, snack inventory, and revenue.

The project models the complete booking workflow using a relational database, including users, theatres, screens, movies, shows, seats, bookings, snacks, snack orders, and payments.

## Key Features

* User registration and account management
* Browse movies and theatres
* View available showtimes
* Select and reserve cinema seats
* Prevent duplicate seat bookings
* Order snacks along with movie tickets
* Manage snack inventory
* Track booking and payment status
* Maintain booking history
* Support different user roles such as customers, cinema staff, and administrators

## Database Design

The database consists of entities such as:

* `USERS`
* `THEATRES`
* `SCREENS`
* `MOVIES`
* `SHOWS`
* `SEATS`
* `BOOKINGS`
* `BOOKED_SEATS`
* `SNACKS`
* `SNACK_ORDERS`
* `PAYMENTS`

The project also includes an **ER diagram, relational schema, functional dependency analysis, candidate key identification, attribute closure, and normalization from 1NF to BCNF**.
